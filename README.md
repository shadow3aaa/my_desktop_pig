# 小猪桌面宠物

一个简单的小猪桌面宠物，基于 Tauri。

小猪形象基于 Google 的 Noto Emoji（猪表情）素材改编。

来源：<https://github.com/googlefonts/noto-emoji>

Noto Emoji 的大多数 SVG/PNG 图像资源采用 Apache License 2.0 许可。本项目对相关素材进行了二次使用与改编。
